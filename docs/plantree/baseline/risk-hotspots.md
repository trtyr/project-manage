# Risk Hotspots — sec-tracker

## 已识别风险

### 1. 技术选型未定
- **风险**：Rust Web 框架、ORM、前端 UI 库尚未确认，影响开发效率
- **缓解**：在 MVP 开发前完成选型，优先选择生态成熟、文档完善的方案
- **状态**：待确认

### 2. Rust + React 全栈开发复杂度
- **风险**：单用户同时负责前后端，开发周期可能较长
- **缓解**：MVP 聚焦核心功能，优先跑通端到端流程
- **状态**：需评估

### 3. 数据模型设计
- **风险**：项目交付服务场景的数据关系可能比预期复杂
- **缓解**：先实现核心实体，后续迭代补充
- **状态**：需验证

## 待评估

- 前后端跨域问题
- 文件上传需求（沟通记录可能包含附件）
- 数据导入/导出需求
