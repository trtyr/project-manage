# Plan: project-manage MVP

## 范围

为科技公司开发项目跟踪管理系统 MVP，实现核心业务模块的端到端流程。

## 核心模块

1. **项目进度** — 项目状态管理、阶段跟踪
2. **客户信息** — 客户产品、安全关注点、背景资料
3. **项目目标** — 项目目的和预期效果
4. **项目跟踪** — 沟通记录、任务规划

## 技术约束

- 后端：Rust（框架待确认）
- 前端：React + TypeScript（脚手架待确认）
- 数据库：PostgreSQL
- 单用户，无登录系统
- 单公司内部部署

## 文件地图

- [roadmap.md](roadmap.md) — 路线图与进度
- [open-questions.md](open-questions.md) — 待确认事项
- `decisions/` — 决策记录
- `topics/` — 方案探讨

## 非目标（MVP 阶段）

- 多用户 / 权限管理
- SaaS 多租户
- 移动端适配（先做桌面 Web）
- 通知系统 / 邮件提醒
- 第三方集成（钉钉/飞书等）
